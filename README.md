## 🌟 Présentation
**Auto-Marketplace** est une plateforme web moderne permettant aux utilisateurs de **vendre et acheter des voitures** en toute simplicité.  
Elle propose une interface utilisateur conviviale, un filtrage avancé des annonces et un tableau de bord complet pour la gestion des utilisateurs et des annonces.  

- 💻 **Code source :** [Repo GitHub](https://github.com/hjiriamir/auto-marketplace-app)
- 🔗 **Démo en ligne :** En préparation (site en cours de déploiement)

---

## 🛠️ Fonctionnalités principales

### Pour les visiteurs / utilisateurs :
- Création et gestion des annonces de voitures  
- Filtrage avancé par marque, modèle, prix, année et autres critères  
- Visualisation des annonces avec images (via Cloudinary)  
- Gestion de compte utilisateur et tableau de bord personnalisé  

### Pour l’admin :
- Authentification sécurisée via **JWT**  
- Gestion complète des annonces et utilisateurs  
- Dashboard d’administration avec statistiques et suivi  

---

## ⚡ Stack technique

### Frontend
- **React.js** & **Next.js** pour le rendu côté client et le routing  
- **TailwindCSS** pour le design responsive  
- Gestion des formulaires et validation côté client  

### Backend
- **Node.js** & **Express.js** pour les API REST  
- **MongoDB** pour la base de données  
- **JWT** pour l’authentification et la sécurité  
- Intégration de **Cloudinary** pour le stockage et la gestion des images  

### DevOps / Outils
- **Git & GitHub** pour le versioning  
- Déploiement prévu sur **Vercel** (frontend) et serveur Node.js (backend)  
- Organisation modulaire du code pour faciliter les évolutions
