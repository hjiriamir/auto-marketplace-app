## 📖 Description

**Auto-Marketplace** est une plateforme web permettant aux utilisateurs de **vendre et acheter des voitures** facilement.  
Elle offre une interface moderne avec gestion d’annonces, filtrage avancé, tableau de bord utilisateur et administration complète.  

**Fonctionnalités principales :**
- Création et gestion d’annonces de voitures
- Filtrage avancé par marque, modèle, prix, année, etc.
- Gestion des utilisateurs et rôles
- Tableau de bord pour suivi des annonces
- Intégration avec Cloudinary pour les images de voitures

## 🛠️ Technologies utilisées

### Frontend
- React.js, Next.js, TailwindCSS
- HTML5 / CSS3
- Responsive Design

### Backend
- Node.js, Express.js
- JWT pour l’authentification
- MongoDB pour la base de données

### Outils et DevOps
- Git & GitHub
- Cloudinary pour le stockage d’images
- Vercel pour le déploiement du frontend
